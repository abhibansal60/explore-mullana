# QA sweep, 2026-10-24

Live site (https://mullana.abhibansal.dev) and a local build served by `wrangler pages dev dist`, so `_headers` and the CSP apply. The local build used the real `shops.json`: 3 checked shops and 50 unchecked places. Tools: the `page-check` skill (headless Chromium), and Playwright scripts for links, images, flows and Core Web Vitals. Viewports: 412x915 phone (also 390x800 in page-check) and 1366x800 / 1280x720 desktop. Throttled runs use 1.6 Mbps, 150 ms latency and a 4x CPU slowdown.

Lighthouse was not run; the run was declined in the session. Core Web Vitals (FCP, LCP, CLS) were measured with PerformanceObserver in Playwright instead.

## What passed

- **Console errors, CSP and failed requests:** none on all 60 sitemap URLs, live and local, on phone and desktop. On the desktop home page, MapLibre cancels tile requests while it flies in (`net::ERR_ABORTED`); that is expected. One desktop run timed out waiting for network idle while the map was still loading tiles; a rerun passed.
- **Links:** 349 distinct links checked. The only broken ones are #5 and #7. `tel:` links are `+91` plus 10 digits for shops, and short codes (112, 108, 1930 and so on) on the helplines page.
- **Images:** no broken images. Every `og:image` resolves.
- **Search:** "chai" 4 rows, "xerox" 1 row and the MMDU guide, "दवाई" 6 rows, "112" the Helplines guide, "bakery" 4, "atm" 2, "zzzz" the empty message.
- **Filters:** category tiles open the right list. Open now showed 3 rows at the time of the run. Back returns to the grid.
- **Map:** it renders with SwiftShader on phone and desktop, with pins and labels for checked shops and rings for unchecked places. 3D is offered. On a phone, Back closes the full-screen map.
- **Speed after #6** (throttled phone): FCP 0.4 to 0.7 s and LCP 0.4 to 1.0 s on every page measured.

## Data quality

`src/data/shops.json` (3 shops): every phone is 10 digits starting 6 to 9, with no duplicates. Hours are valid `HH:MM` with open before close. Coordinates are all within 0.2 km of the market. `verified` is a valid month. `bansal-light-decorator` has no `googleMaps` link; the page hides that button, so nothing breaks.
